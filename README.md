# Heart & Blood Flow – Dual-colour LED model

Interactive 3D heart (labelled parts, blue = impure / red = pure blood flow) with the wiring and Arduino code for a 9-LED physical model.

- `index.html` – the whole 3D project (single file, no install, works on phones)
- `arduino/heart_blood_flow.ino` – LED sketch
- `qr.png` – QR code that opens the live page

Live page: https://poojaharan-s.github.io/3d-heart-model-ME/
